# Slide Design Tips

Quick colour advice for building decks in Calliope Canvas. Pick a theme from the footer selector, then keep these in mind.

Adapted from [Top 10 Colour Schemes That Make Slides Memorable](https://www.mypresentationdesigner.com/top-10-colour-schemes-that-make-slides-memorable/).

## General rules

- **Stick to 3–4 main colours.** More than that and slides start to feel noisy.
- **Stay consistent.** Use the same theme for every slide in a deck.
- **Test on the real screen.** Projectors and TVs wash out colours; check your deck on the display you'll present on.
- **Use semantic colours, not fixed ones.** Style slides with `text-primary`, `bg-surface`, `text-muted` and the other theme utilities so your deck works in every theme.

## Tips by theme

Light themes work best in bright rooms and on projectors. Dark themes suit dim rooms, screens and long talks.

### Light themes

| Theme | Good for | Tip |
|---|---|---|
| Light | Everyday decks, shared screens | The safest choice on unknown projectors; add images to keep it from feeling bare. |
| Sepia | Storytelling, history, long reads | Warm and easy on the eyes; pair with serif headings for a classic feel. |
| Lavender fields | Creative briefs, design reviews | Calm and soft; keep illustrations in the same violet family. |
| Winter chill | Health, science, clean data | Icy and clinical; works well with simple line charts. |
| Above the surface | Nature, wellbeing, research | Earthy and quiet; let the green buttons mark the actions that matter. |
| Eggs for breakfast | Friendly intros, onboarding | Light and cheerful; use the amber accent for one highlight per slide. |
| Graphite | Corporate decks, reports | Add a single accent colour for the one number or chart you want people to remember. |
| Admiral | Finance, credibility-focused pitches | Use red sparingly. It's powerful, but feels alarming if it's everywhere. |
| Sorbet | Workshops, education, wellness | Pair with simple icons and clean typography for a modern look. |
| Seaglass | Tech pitches, product showcases | Leave generous white space so slides feel crisp. |
| Ember | Business and marketing reports | Save the bold colour for key data points and calls to action. |

### Dark themes

| Theme | Good for | Tip |
|---|---|---|
| Dark | Tech talks, demos, code | A neutral default for dim rooms; code snippets read well on it. |
| Contrast | Urgent messages, accessibility | Highest contrast; great for short talks, tiring over long sessions. |
| Sunset | Keynotes, product launches | Warm and bold; keep slides sparse so the orange stands out. |
| Forest | Calm, focused walkthroughs | Low-glare green; good for long sessions and workshops. |
| Stormy morning | Strategy, planning reviews | Muted and serious; let charts carry the colour. |
| Ocean tide | Data and dashboards | Teal on deep sea; cyan highlights make key numbers pop. |
| Space berries | Creative pitches, events | Playful and loud; best for short, high-energy talks. |
| Desert dusk | Brand stories, culture decks | Rich and moody; use large images and few words. |
| Night sands | Heritage, craft, premium stories | Gold on olive; keep text short and let the warmth set the tone. |
| Italian leather | Craft, food, lifestyle | Warm brown with sand text; pair with close-up photography. |
| Woodland | Sustainability, environmental topics | Let the lime green highlight progress and wins; keep the rest calm. |
| Gilded night | Premium launches | Use gold for highlights only; a little goes a long way. |
| Neon orchid | Startup pitches, youthful brands | Use gradients sparingly and always check that text stays readable. |

## Accent colours

- **Accents are for emphasis.** Use `text-accent` or `bg-accent` on one element per slide, not on body text.
- **Keep body text in `text-text` or `text-muted`.** Every theme guarantees these are readable.
